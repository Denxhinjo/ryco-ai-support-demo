The Problem

  • IT helpdesk received a high volume of support requests via ad-hoc emails and Teams messages
  • Requests lacked consistent structure — missing urgency, affected system, or contact details
  • Agents spent significant time chasing missing information rather than resolving issues
  • No SLA tracking; priority was assigned manually and inconsistently
  • Peak-hour bottlenecks caused lengthy delays in first response

The Solution

  • Built a Copilot Studio virtual agent deployed to Microsoft Teams
  • Guided intake flow collects: email, issue description, affected system, urgency level
  • Power Automate flow validates input, creates the ticket, sends confirmation
  • Tickets auto-routed to correct team (Network / Hardware / Software / Access)
  • First-response time reduced significantly for automated ticket categories

How the Agent Works

A five-step guided conversation that turns a vague Teams message into a structured, routed, and confirmed support ticket.

01

User Initiates

Employee messages the IT Support bot in Teams with a free-text description of their issue.

→
02

Agent Collects Info

Bot asks for work email, affected system, and urgency level using adaptive card prompts.

→
03

Power Automate Fires

A triggered flow validates the data, categorises the ticket, and routes it to the right team queue.

→
04

Ticket Created

Ticket is logged in the ITSM system with all fields pre-populated. Ticket ID returned to user.

→
05

Confirmation Sent

User receives confirmation in Teams + email with ticket number, assigned team, and estimated SLA.

Technology Stack

CS

Microsoft Copilot Studio

Conversational AI platform used to design, train and publish the virtual agent dialog flows.

PA

Power Automate

Cloud flows handle ticket creation, data validation, team routing, and email notifications.

T

Microsoft Teams

Primary deployment channel — agent is available as a Teams app for all employees.

SP

SharePoint / Dataverse

Structured ticket data and entity lists stored in Dataverse; lookup tables in SharePoint.

IT

ITSM Integration

Connector to the internal IT service management system via HTTP action in Power Automate.

✉

Exchange / Outlook

Automated confirmation and escalation emails sent via the Office 365 Outlook connector.
